# Ivorovi Assessment Platform

AI-assisted screening and assessment platform for higher education: admissions, academic examinations,
placement assessments, evaluation, proctoring and analytics. One codebase serves multi-tenant SaaS, dedicated
cloud and on-premises deployments.

**Current state:** Phase 0 (foundation) is complete and verified in CI. See [Phase 0 report](docs/phase-0-report.md) and
[tracker](docs/tracker.md). Phase 1 approved ([plan](docs/phase-1/plan.md), [amendment 1](docs/phase-1/plan-amendment-1.md), [design system](docs/design/design-system.md)); CI is green, and implementation starts on approval of the open Phase 1 decisions.

## Quick start

Requires Docker, JDK 21, Node 22 and pnpm 10. Full instructions are in
[docs/runbooks/local-development.md](docs/runbooks/local-development.md).

```bash
./scripts/dev-setup.sh
```

```bash
./gradlew :backend:api:bootJar && (cd frontend && pnpm install --frozen-lockfile && pnpm build)
```

```bash
docker compose -f deploy/compose/compose.yaml --profile app up -d --build --wait
```

Open http://localhost:8081 and sign in as `alice.admin@aurora.test`. The password is `DEV_USER_PASSWORD` in
`deploy/compose/.env`. Verify the deployment with `./scripts/smoke-test.sh`.
