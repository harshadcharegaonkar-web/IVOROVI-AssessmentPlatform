# Ivorovi Assessment Platform

AI-assisted screening and assessment platform for higher education: admissions, academic examinations,
placement assessments, evaluation, proctoring, and analytics. One codebase serves multi-tenant SaaS,
dedicated cloud, and on-premises deployments.

**Current state:** architecture baseline only. No runnable code yet. See `docs/tracker.md`.
